## 📖 專題選題動機與介紹
大學生與上班族每天最常遇到的困擾就是「今天到底要吃什麼？」。本專題以商業設計美學為核心，結合物理減速動畫、Web Audio 實時音效合成、以及完整的前端資料管理系統 (CRUD)，打造兼具視覺美感與實用性、專治三餐選擇困難症的智慧食物決策轉盤！

### ✨ 核心功能特色
1. **六大分類細項切換**：
   - 🌅 **早餐 (Breakfast)**：蛋餅、飯糰、鐵板麵、肉蛋吐司等
   - 🍱 **午餐 (Lunch)**：排骨便當、豚骨拉麵、鍋貼水餃、石鍋拌飯等
   - 🍲 **晚餐 (Dinner)**：小火鍋、居酒屋、熱炒、麻辣燙、炸雞披薩等
   - 🍜 **麵食特輯 (Noodles)**：牛肉麵、鍋燒意麵、炸醬麵、涼麵等
   - 🍰 **甜點下午茶 (Dessert & Drinks)**：手搖飲、豆花、肉桂捲、可麗露等
   - 🌙 **深夜宵夜 (Late Night)**：鹽酥雞、清粥小菜、串烤、關東煮等
2. **完整 CRUD 資料管理功能（期末加分 10 分項目）**：
   - **新增 (Create)**：可隨時自訂菜單、自選 Emoji 圖示與風味標籤
   - **讀取 (Read)**：依分類即時檢視所有美食候選清單
   - **編輯 (Update)**：點擊鉛筆即可修改餐點名稱、標籤與圖示
   - **刪除 (Delete)**：一鍵刪除不喜歡的選項
   - **即時開關 (Toggle)**：不用刪除也能暫時剔除今天不想吃的菜色，轉盤即時重繪
   - **資料保存 (LocalStorage)**：重新整理頁面資料完全不遺失，亦提供一鍵還原原廠預設
3. **極致動態體驗與互動**：
   - **流暢物理減速**：採用 Cubic Easing 曲線，模擬真實指針機械阻尼
   - **Web Audio 實時音效**：無需外部音檔，轉動喀噠聲 (Tick) 與中獎慶祝音效零延遲
   - **彩帶噴灑慶祝**：中獎觸發 Canvas Confetti 煙火特效
   - **Google Maps 美食地圖串接**：中獎後可一鍵跳轉 Google 地圖，直接搜尋附近的得獎美食！
   - **歷史抽籤紀錄**：記錄歷次抽籤結果，可隨時回顧

## 🌐 部署上線教學（拿滿期末加分）

### 步驟 1：建立公開 GitHub 儲存庫 (Repo)
1. 登入一位組員的 GitHub，點擊右上角 `New repository`。
2. Repository name 設為例如：`daily-food-wheel`。
3. 務必勾選 **Public**（公開），點擊 **Create repository**。
4. 到 Repository 的 `Settings` → `Collaborators`，將其餘三位組員邀請加入。
5. 在本地終端機執行推入：
```bash
cd /Users/chenrui/.gemini/antigravity/scratch/food-wheel
git init
git add .
git commit -m "feat: 初版食物轉盤上線 (支援六大分類與CRUD管理)"
git branch -M main
git remote add origin https://github.com/<你的帳號>/daily-food-wheel.git
git push -u origin main
```

### 步驟 2：部署到 Vercel (1 分鐘完成)
1. 到 [vercel.com](https://vercel.com) 註冊/登入（建議直接以 GitHub 帳號登入）。
2. 點擊 **Add New...** → **Project**。
3. 選擇剛剛建立的 `daily-food-wheel` 專案，點擊 **Import**。
4. Framework Preset 保持 Other，直接點擊 **Deploy**！
5. 部署完成後即可獲得一個公開上線網址（例如：`https://daily-food-wheel.vercel.app`）。

## 📝 投影片必備：3 處真實改善紀錄 (Changes)
課程指南要求簡報最後需列出至少 3 處具體改善，我們已為第 19 組整理好前後對比事實依據：

1. **改善項目一：轉盤扇形文字排版與自適應字級**
   - **原問題**：初版轉盤若選項超過 8 項時，較長的菜色名稱會與外圈鉚釘重疊溢出。
   - **決策與修改**：改用動態自適應字級演算法，並針對超過 10 個字元之美食名稱加上智能省略號，確保在各尺寸手機與電腦皆維持精緻視覺。
   - **驗證方式**：在管理中心新增 12 個以上自訂長名稱項目，確認轉盤旋轉與文字完全清晰整齊。

2. **改善項目二：轉動物理手感與喀噠聲 (Tick) 延遲**
   - **原問題**：傳統網頁若載入 mp3 外部音訊常因網路延遲導致音畫不同步，且容易被瀏覽器自動播放政策阻擋。
   - **決策與修改**：改以純 JavaScript 的 `Web Audio API` 實時合成三角波與正弦波，並在指針每次跨越扇形邊界瞬間觸發，達成零延遲真實機械阻尼手感。
   - **驗證方式**：開啟不同速度（疾速、標準、漫步），確認指針晃動時喀噠聲與扇形通過完全精準同步。

3. **改善項目三：增加「即時勾選」與「Google 地圖串接」**
   - **原問題**：使用者雖然想隨機決定，但當天可能有某些菜色「完全不想吃」（例如今天胃不舒服不想吃辣或炸的），若必須把項目整個刪掉，下次想吃又得重打。
   - **決策與修改**：在右側增加即時勾選 Checkbox，不需刪除即可一秒排除；並在抽中結果彈窗加入「Google 地圖一鍵搜尋周邊」，直接幫使用者找出哪裡買得到。
   - **驗證方式**：取消勾選兩道菜，轉盤立刻自動重算等分角重新繪製；中獎後點擊地圖按鈕可順暢在新分頁展開附近店家搜尋。
